# Histórias de Usuário (User Story)

- Como cidadão, quero visualizar o plano decenal de maneira simplificada para facilitar a leitura, visto que se trata de um documento muito extenso.
  
- Como membro da Secretaria *X* do estado, quero poder carregar os dados de maneira intuitiva para facilitar o trabalho.

- Como cidadão, quero visualizar o andamento dos compromissos para saber se o estado está cumprindo suas promessas.

- Como membro da Secretaria *X* do estado, quero monitorar o cumprimento do Plano Decenal para saber se as intervenções estaduais estão sendo efetivas.

- Como membro da Secretaria *X* do estado, quero monitorar o cumprimento do Plano Decenal através de gráficos e tabelas interativas para facilitar a análise dos dados.

- Como membro da Secretaria *X* do estado, quero poder filtrar as informações para permitir uma visualização mais específica.

- Como criança e adolescente, quero poder visualizar de maneira divertida o plano decenal para entender sobre o projeto.

- Como usuário PCD, quero que a plataforma tenha controles de contraste, tamanho da fonte e compatibilidade para leitores de tela para poder acessar as informações.
