# Histórias de Usuário (User Story)

Os atores seguem a hierarquia de perfis do sistema: SEDEF herda tudo do Conselho/Secretarias, que herda tudo do Público Geral.

## Público Geral

- Como cidadão, quero visualizar os 23 problemas públicos e seus Compromissos Decenais para entender as prioridades do estado para crianças e adolescentes. *(RF01)*

- Como cidadão, quero navegar pela estrutura hierárquica do Plano Decenal (Problema Público → Compromisso → Objetivo → Linha de Ação → Tarefa) para compreender como as ações se relacionam entre si. *(RF02)*

- Como cidadão, quero visualizar o andamento dos compromissos — status das tarefas e valores dos indicadores — para saber se o estado está cumprindo suas promessas. *(RF03)*

- Como cidadão, quero buscar registros do Plano por palavra-chave para encontrar rapidamente as informações que me interessam. *(RF04)*

- Como cidadão, quero filtrar as informações por compromisso, indicador, responsável ou período de tempo para visualizar dados de forma mais específica. *(RF05)*

- Como cidadão, quero exportar os dados filtrados em Excel, CSV ou PDF para compartilhar ou analisar as informações fora do sistema. *(RF06)*

- Como cidadão, quero ver a data e hora da última atualização de cada item monitorado para saber se as informações estão atualizadas. *(RF07)*

- Como cidadão, quero visualizar gráficos de progresso de cada indicador, diferenciados visualmente por tipo e filtráveis por ano, para acompanhar a evolução ao longo do tempo. *(RF16, RF17, RF18)*

- Como cidadão, quero ver o Responsável Principal e os Colaboradores de cada Linha de Ação para saber quem é responsável por cada iniciativa. *(RF19)*

- Como usuário, quero ativar o modo de alto contraste para visualizar o conteúdo com melhor legibilidade. *(RF10)*

- Como cidadão, quero alterar o idioma da interface entre português e espanhol para acessar as informações no idioma de minha preferência. *(RF26)*


## Conselho Estadual / Secretarias

- Como membro do Conselho/Secretaria, quero que minha sessão seja encerrada ao fazer logout e revogada ao expirar para que meu acesso não fique exposto indevidamente. *(RF23)*

- Como membro do Conselho/Secretaria, quero inserir novos registros do Plano Decenal para manter os dados atualizados sem depender de terceiros. *(RF12, RF25)*

- Como membro do Conselho/Secretaria, quero editar registros já existentes do Plano Decenal para corrigir ou atualizar informações quando necessário. *(RF22, RF25)*

- Como membro do Conselho/Secretaria, quero carregar dados por meio de planilha para facilitar a inserção em lote de forma intuitiva e sem erros manuais. *(RF21, RF25)*


## SEDEF (Administrador)

- Como administrador SEDEF, quero gerenciar contas de usuário e atribuir ou alterar perfis de acesso para controlar quem pode visualizar ou modificar os dados do sistema. *(RF09, RF20, RF24)*

- Como administrador SEDEF, quero consultar o registro de auditoria das ações realizadas no sistema — com usuário, tipo de ação, data e hora — para identificar responsáveis por alterações e garantir a integridade dos dados. *(RF13)*

- Como administrador SEDEF, quero aprovar a conclusão de tarefas para garantir controle sobre o progresso registrado no Plano Decenal. *(RF24)*

- Como administrador, quero consultar o histórico de atualizações de uma tarefa — com data, conteúdo anterior e novo — para acompanhar a evolução do que foi alterado. *(RF08)*

## Crianças e Adolescentes

- Como criança ou adolescente, quero acessar uma área com explicação acessível dos Compromissos Decenais para entender como o estado se comprometeu com o meu bem-estar. *(RF27)*

- Como criança ou adolescente, quero encontrar facilmente canais de acolhimento e socorro para saber a quem recorrer em situações de vulnerabilidade. *(RF28)*


## Usuário com Deficiência (PCD)

- Como usuário PCD, quero ajustar o tamanho de fonte e ter compatibilidade com leitores de tela para poder acessar todas as informações do sistema com autonomia. *(RNF01)*
